## Validation Result

**Lab 03 runtime validation passed for this specific Ubuntu 26.04 LTS aarch64 VM using
SentinelLite source commit `d1775f0ca09d714f5ed9d681af90f216c1c39e8e`.** The recorded workflow
completed local installation checks, a synthetic demo, JSON report review, static HTML
export and local browser viewing. It produced one report containing three synthetic alerts.

The demo uses synthetic data only. The dashboard is local static HTML generated from
existing local JSON reports; it does not provide a server or live monitoring. ARM-SecNet
provides the ARM64 lab environment and SentinelLite provides the optional local CLI. They
remain separate repositories with no runtime dependency.

These screenshots record a successful workflow on one VM, not a compatibility matrix or
a security-effectiveness assessment. The file-presence validation script verifies that
the documentation and eight screenshots exist; it does not rerun this workflow.
