## Evidence Boundaries

- Mark demo data as synthetic. Do not use real logs or unrelated host reports in this lab.
- Review and redact personal paths, user names or host identifiers before committing images.
- Do not capture credentials, tokens or unrelated desktop content.
- The HTML is static and offline: no server, network requests, live monitoring or automatic
  remediation. No raw evidence is dumped by default.
- Do not describe screenshots as proof of production protection, EDR, antivirus, SIEM/SOC,
  real AI/LLM capability or completed validation on other ARM64 environments.
- Mark failures, warnings and unperformed steps honestly. Repository file checks validate
  documentation presence; they do not run SentinelLite or prove this VM workflow succeeded.

Only add a completed result summary after the corresponding run record and reviewed
evidence are available. Existing V1.0 test results remain unchanged.
